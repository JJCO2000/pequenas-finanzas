# STEP 3 - PDF Visual Alignment (historico)

Este documento describe una etapa anterior del MVP. STEP 3 adapto el PDF a portrait y sirvio para validar escenarios, personajes y lenguaje visual.

**No es la regla visual vigente.**

Plan 2.1 sustituyo la orientacion portrait por una experiencia **landscape/horizontal**, manteniendo la arquitectura Plan 1.1. La fuente visual maestra actual es el diseno original de Canva; el PDF permanece como referencia secundaria.

Elementos heredados que siguen vigentes:

- bosque/dinosaurios para portada;
- agua/islas/volcan/brujula para mapa;
- cueva/fosiles para Tema;
- pasto/huellas para Actividad;
- terracota/estantes/huevos para Canje;
- assets runtime centralizados en `src/registry/assets.ts`;
- economia, progreso y base de datos fuera de la UI.

Ver `docs/product/PLAN_PEQUENAS_FINANZAS_2_1.md` para la regla actual.
