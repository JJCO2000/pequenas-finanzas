# Plan Pequenas Finanzas 1.1 - Nota de compatibilidad visual

Plan 1.1 sigue siendo la **estructura y arquitectura tecnica** del proyecto: SSOT, repositorios, SQLite encapsulado, economia central, juegos modulares, registries y assets centralizados.

La regla visual portrait que existia durante STEP 3 queda **historica y sustituida por Plan 2.1**.

Regla vigente:

- Plan 1.1 gobierna estructura y limites tecnicos.
- Plan 2.1 gobierna diseno, navegacion y mecanicas de experiencia.
- La experiencia principal es landscape/horizontal.
- Canva es la fuente visual maestra; el PDF queda como referencia secundaria.
- Mapa, Tema, Actividad y Canje deben conservar el mundo visual reconocible del diseno original.
- Ningun cambio visual puede duplicar datos ni mover logica de economia/progreso/base de datos a las pantallas.

Ver `docs/product/PLAN_PEQUENAS_FINANZAS_2_1.md`.
