# Benchmarking — Experiencia Global Pequeñas Finanzas

## Objetivo
Extraer patrones ya resueltos de productos con fuerte engagement para mejorar el **loop global** sin cambiar la identidad ni la lógica financiera de Pequeñas Finanzas.

| Referencia | Fortaleza usada | Traslado a PF | Copia directa |
|---|---|---|---|
| Prodigy Math | Mundo + quests + rewards + pets | mapa como aventura, misión actual, compañero y retorno al mundo | No |
| Duolingo | Path + progreso visible + siguiente objetivo | barra de etapa 1/9..9/9 y CTA de misión actual | No |
| Finch | Companion + quests + celebración/reward | personaje presente y celebración in-world con recompensa | No |

## Principio de diseño
La educación no debe ser la pantalla principal con decoración alrededor. El jugador debe percibir primero:

**“Tengo una misión dentro de un mundo y mi decisión hace avanzar algo.”**

El contenido financiero sigue siendo el objetivo pedagógico, pero la interfaz se expresa como videojuego.

## Límites
- No se incorporan streaks, leaderboards ni misiones diarias en este bloque.
- No se añade editor de themes.
- No se cambian los siete minijuegos internamente.
- No se crean dependencias de red ni contenido remoto.
